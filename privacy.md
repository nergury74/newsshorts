# Privacy Policy

Effective date: November 2, 2026 (updated November 2, 2026: read-only channel check added)

This policy explains how **NewsShorts Uploader** ("the app") handles Google user data. The app is a private tool used only by the owner of the YouTube channel 아빠 너구리TV (contact: nergury74@gmail.com).

## Use of YouTube API Services

The app uses YouTube API Services. By using the app, you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

## What data the app accesses

When the channel owner signs in with Google, the app receives an OAuth access token and refresh token with the `youtube.upload` and `youtube.readonly` scopes. With the upload permission the app sends the owner's own video files and their title, description, tags and privacy setting to YouTube, and receives back the ID of each uploaded video. With the read-only permission the app reads only the ID and title of the signed-in channel, to confirm that uploads go to the correct channel.

The app does not access, collect or store any other Google account data, any viewer data, or any data about other YouTube users.

## How the data is used

The token is used only to upload videos that the channel owner created to the owner's own channel. The returned video ID is used only to show the owner a link to the uploaded video.

## Storage and sharing

The OAuth token and the upload log are stored only on the channel owner's own computer. They are not sent to any server operated by the app, and they are not sold, shared with or disclosed to any third party.

The app's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Retention and deletion

The token stays on the owner's computer until the owner deletes it or revokes access. Access can be revoked at any time from the Google security settings page: [https://myaccount.google.com/permissions](https://myaccount.google.com/permissions). Revoking access stops all uploads immediately.

## Changes

If this policy changes, the updated version will be published on this page with a new effective date.
