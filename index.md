# NewsShorts Uploader

**NewsShorts Uploader** is a private, single-user automation tool operated by the creator of the YouTube channel **아빠 너구리TV** (Dad Raccoon TV).

## What it does

The channel owner records a short narration every morning. A program on the owner's own Mac turns that recording into a vertical YouTube Shorts video. NewsShorts Uploader then uploads that finished video, with its title, description and hashtags, to the owner's own YouTube channel through the YouTube Data API.

- Only the channel owner uses this tool. It has no other users and is not offered to the public.
- It only uploads videos that the owner created. It does not read, collect or change any other YouTube data.
- It requests only the permission needed to upload videos (`youtube.upload`).
